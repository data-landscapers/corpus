The Maturity Assessment will be presented through an interactive map with links to country reports and indicator reports.


1. Map of Africa. Big as possible. Must show island states.
2. Light grey colour for no evidence. Distinct 5 colour scale from red to green showing assessment.
3. Hover over country - tooltip with 1 sentence summary explaining score.
4. Click country - Display's country info in right sidebar
5. Double click country - goes to the indicator bookmark on the country's maturity assessment report.
6. Above map = two dropdowns topics and indicators (indicators include sub-indicators and display only the selected topic's indicators)
7. Legend shows generic assessment description
8. Wide right-hand sidebar split horizontally in two.
9. Top-half describes the scale criteria for this indicator. Includes a button link to maturity report for this indicator.
10. Bottom half - A single click on a country displays content for this country (content tbc)
11. On the same row as the dropdowns: buttons to metadata and download csv (all or this indicator)
12. Somewhere in whitespace near map. A box showing changes to scores in past six months. (excluding initial baseline)
