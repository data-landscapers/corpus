# Malawi

## Address register

**Addresses in service.** [In February 2024 MACRA said it coordinates the National Addressing System Project](<https://macra.mw/national-addressing-project/>). [Its deliverables include street naming, property numbering and a national address database](<https://macra.mw/national-addressing-project/>).

**Nationwide.** No source found since October 2023 says the addressing system covers the whole country. The nearest held fact: [the project aims to give every property in Malawi a physical address](<https://macra.mw/national-addressing-project/>).

**Used by services.** No source found since October 2023 says other services use the address system. The nearest held fact: [MACRA calls it a multi-stakeholder programme, with a postcode directory among its deliverables](<https://macra.mw/national-addressing-project/>).
