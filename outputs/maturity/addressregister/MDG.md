# Madagascar

## Address register

**Addresses in service.** In July 2024 L'Express reported that the tax directorate DGI [was training staff of Antsiranana commune to set up addressing and tax census operations](<https://www.lexpress.mg/2024/07/antsiranana-des-efforts-pour-booster.html>). Drones were to survey the town before the address database was built. The work was part of an effort to raise the commune's tax revenue.

**Nationwide.** No source found says an addressing system covers the whole country, rural areas included. The nearest fact found is [the addressing work in Antsiranana in 2024](<https://www.lexpress.mg/2024/07/antsiranana-des-efforts-pour-booster.html>), which concerns one commune and its own staff.

**Used by services.** No source found says the post, emergency services or utilities use an address system. The Antsiranana addressing [was set up alongside a tax census](<https://www.lexpress.mg/2024/07/antsiranana-des-efforts-pour-booster.html>), in work led by the tax directorate.

***Also on file***. None found.

***Not found***. No source found says an addressing system is in service in Madagascar. Nor has any source reported how far the Antsiranana work went.
