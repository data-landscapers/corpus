# Uganda

## Tax

**Online filing.** [In July 2026 the Uganda Revenue Authority's File a Return page set out filing on the URA web portal](<https://ura.go.ug/en/domestic-taxes/returns/>). The taxpayer logs in with a TIN, uploads a completed return template and submits it. An acknowledgement receipt is emailed. [The Ultimate Post reports URA awarded an e-tax2 software contract (80bn, 10-year) to a joint venture](<https://ultimatepost.dantty.com/post/10745>). It says the rollout is late by 4 years and the contractor has yet to start work.

**Electronic payment.** No source found since October 2023 says taxes can be paid electronically through the tax authority's system. The nearest fact: [in July 2026 the URA's web portal took returns from taxpayers logging in with their TIN](<https://ura.go.ug/en/domestic-taxes/returns/>).

**Mostly online.** No source found since October 2023 says online filing is mandatory or used for half or more of returns. The nearest fact: [in July 2026 the URA said taxpayers submit completed return templates through its web portal](<https://ura.go.ug/en/domestic-taxes/returns/>).
