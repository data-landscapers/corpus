# South Africa

## Open data policy

**Policy adopted.** South Africa has an open data policy framework that is not known to be adopted. [Research ICT Africa says it developed the Open Data Policy Framework in South Africa under its DataCipation project with GIZ and AUDA-NEPAD](<https://researchictafrica.net/project/datacipation-shaping-harmonised-and-inclusive-digital-and-data-policies-in-africa/>). The project page, from September 2026, does not say who commissioned the framework or whether the government has approved it, and no source held says it has.

**Portal run and data published.** [Research ICT Africa's project page names no government open data portal run under the framework and no data published under it](<https://researchictafrica.net/project/datacipation-shaping-harmonised-and-inclusive-digital-and-data-policies-in-africa/>). Because the framework is not known to be adopted, there is nothing yet for a portal to run under. No source held names a national open data portal or data that public bodies have published under an open data policy.

[national rapid deployment GIS database](<https://techcentral.co.za/icasa-moves-to-mandate-national-infrastructure-database/280056/>); [Sadis broadband GIS](<https://techcentral.co.za/sa-finally-has-a-broadband-map-and-it-reveals-where-the-gaps-are/279660/>); [MzansiXchange](<https://www.globalgovernmentforum.com/south-africa-pilots-government-data-exchange-to-improve-policymaking-and-service-delivery/>).

***Not held***. Nothing held names an open data policy, or says there is none.
