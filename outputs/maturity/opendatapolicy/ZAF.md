# South Africa

## Open data policy

**Policy adopted.** South Africa has an open data policy framework, and no source found says it has been adopted. [Research ICT Africa says it developed the Open Data Policy Framework in South Africa under its DataCipation project with GIZ and AUDA-NEPAD](<https://researchictafrica.net/project/datacipation-shaping-harmonised-and-inclusive-digital-and-data-policies-in-africa/>). The project page, from September 2026, does not say who commissioned the framework or whether the government has approved it, and no source found says it has.

**Portal run and data published.** [Research ICT Africa's project page names no government open data portal run under the framework and no data published under it](<https://researchictafrica.net/project/datacipation-shaping-harmonised-and-inclusive-digital-and-data-policies-in-africa/>). No source found reports because the framework to be adopted, there is nothing yet for a portal to run under. No source found names a national open data portal or data that public bodies have published under an open data policy.
