# Botswana

## Open data policy

**Policy adopted.** Botswana has a national Open Data Policy in draft. [Terms of reference issued in March 2026 for a programme of open data hackathons funded by the European Union refer to the policy's expected adoption by Parliament](<https://haus.fi/en/topical/terms-of-reference-support-for-open-data-hackathons-and-forum-in-botswana-phase-2/>). No source found says the policy has been approved or launched, gives the date it was written or names the ministry that wrote it.

**Portal run and data published.** No source found names a government open data portal in Botswana, or a ministry that has released data under the policy. [The hackathon programme was planned around the policy's adoption](<https://haus.fi/en/topical/terms-of-reference-support-for-open-data-hackathons-and-forum-in-botswana-phase-2/>), which had not taken place by March 2026. No source found says which ministry would run a portal, or whether public bodies already release data in open formats ahead of the policy.

***Also on file***. [SmartBots Lab](<https://haus.fi/en/topical/terms-of-reference-support-for-open-data-hackathons-and-forum-in-botswana-phase-2/>); [National Open Data Hackathons](<https://haus.fi/en/topical/terms-of-reference-support-for-open-data-hackathons-and-forum-in-botswana-phase-2/>).

***Not found***. No source found says an open data policy is adopted and still running.
