# Sudan

## Satellite data in agriculture

**Satellite service.** [FAO published a technical report assessing Sudan's cultivated cropland for the June-October 2024 summer season](<https://openknowledge.fao.org/items/05d795aa-0d58-4f1a-a799-3664e2fadb31>). [It used remote sensing, with biomass productivity, agricultural indices, rainfall data and high-resolution imagery](<https://openknowledge.fao.org/items/05d795aa-0d58-4f1a-a799-3664e2fadb31>). [It found 19,148,190 hectares, 6.4 percent above the 2018-2022 baseline](<https://openknowledge.fao.org/items/05d795aa-0d58-4f1a-a799-3664e2fadb31>).
