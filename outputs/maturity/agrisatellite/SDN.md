# Sudan

## Satellite data in agriculture

**Satellite service.** [FAO published a technical report assessing Sudan's cultivated cropland for the June-October 2024 summer season](<https://openknowledge.fao.org/items/05d795aa-0d58-4f1a-a799-3664e2fadb31>). [It used remote sensing, with biomass productivity, agricultural indices, rainfall data and high-resolution imagery](<https://openknowledge.fao.org/items/05d795aa-0d58-4f1a-a799-3664e2fadb31>). [It found 19,148,190 hectares, 6.4 percent above the 2018-2022 baseline](<https://openknowledge.fao.org/items/05d795aa-0d58-4f1a-a799-3664e2fadb31>). [FAO's WaPOR catalogue describes a Sudan Drought Monitoring Tool that uses remote-sensing data to derive drought indices and assess yield gaps in Gedaref State](<https://www.fao.org/in-action/remote-sensing-for-water-productivity/applications-and-uses/applications-catalogue/product-detail/sudan-drought-monitoring-tool939008e8-4992-4ca4-96a4-249f26e50cc1/en>). [FAO's WaPOR page lists the Gezira Scheme as a pilot area, with the agriculture ministry, the Agricultural Research Corporation and the meteorological authority among partners](<https://www.fao.org/in-action/remote-sensing-for-water-productivity/country-activities/sudan/en>).
