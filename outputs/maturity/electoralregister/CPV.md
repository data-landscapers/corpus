# Cape Verde

## Electoral register

**Digital roll.** [Cabo Verde's CNE president said the current electoral database, created in 2007, and its computerised management system are outdated, and asked the Government for a new database for 2026](<https://cne.cv/sala_de_imprensa_/cne-reivindica-nova-base-de-dados-para-as-eleicoes-de-2026/>). [The DGAPE ReDiaspora page describes diaspora voter registration via the Portal Consular with APIs to insert requests into the Base de Dados do Recenseamento Eleitoral (BDRE) and integration with the Sistema Integrado de Gestão Eleitoral (SIGE)](<https://dgape.cv/rediaspora/>).

**Open for checking.** [Cabo Verde's CNE said the cadernos de recenseamento would be displayed for consultation until 23 March 2026, with claims for omissions or improper entries accepted to 28 March, ahead of the 17 May legislative elections](<https://cne.cv/sala_de_imprensa_/legislativas-2026-recenseamento-suspenso-a-partir-de-13-de-marco/>).

**Linked to ID.** [The DGAPE ReDiaspora page says the system interoperates with the SNIAC database and registers voters automatically when they request a passport or national ID card (CNI), using their data if not already registered](<https://dgape.cv/rediaspora/>).
