# Botswana

## Rule on sending data abroad

**Protected when sent abroad.** Botswana's Data Protection Act has been in effect since January 2025. [Mmegi reported on 25 November 2025](<https://www.mmegi.bw/business/govt-moves-to-in-house-local-data/news>) that it allows transfers abroad only to approved countries.

**Open without permission each time.** Transfers to approved countries need no case-by-case permission. The [same report](<https://www.mmegi.bw/business/govt-moves-to-in-house-local-data/news>) says the Act requires a copy of the data to remain in Botswana. No source found says how that requirement works beside transfers to approved countries, so openness is not shown.

**Published way to send data without asking.** [A DIAL expert comment of 15 June 2026](<https://dial.global/africas-digital-future-seamless-data-flows/>) says Botswana has an adequacy list of countries data may go to. Only two African countries were on it.

**Open to African partners.** Botswana has not ratified the Malabo Convention. [The Minister told Parliament on 7 December 2023](<https://dailynews.gov.bw/news-detail/76876>) that it was not yet ratified, and [the African Union list of 2 February 2026](<https://au.int/sites/default/files/treaties/29560-sl-AFRICAN_UNION_CONVENTION_ON_CYBER_SECURITY_AND_PERSONAL_DATA_PROTECTION_0.pdf>) shows no action.
