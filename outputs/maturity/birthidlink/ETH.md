# Ethiopia

## Interoperability of birth registration and digital id

**Civil register linked to ID.** [The EBC reports the new Addis Ababa system is set to create interoperability between sectors including Health, Immigration, Courts and the National ID Program](<https://www.ebc.et/english/Home/NewsDetails?NewsId=3422>). [Addis Ababa Mayor Adanech Abiebie said the new city civil registration system facilitates data sharing among Immigration, Health, Courts, the National ID program and others, with no event or direction of exchange stated](<https://www.amn.gov.et/en/mayor-launches-new-digital-civil-registration-and-residency-service-platform/>). [NIDP says Fayda is being requested to be delivered for all vital events (birth, marriage, death) at the Civil Registration and Vital Events Agency, with system integration discussions ongoing](<https://connect.mosip.io/resources_pdf_2026/Inclusive_Identity_at_Scale_Ethiopia.pdf>).
