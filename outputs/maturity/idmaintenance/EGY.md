# Egypt

## National maintenance of id and credentials systems

**Operated nationally.** [The national number project is run with technicians of the Civil Status Organization](<https://www.citc.com.eg/National%20ID%20SYSTEM.html>). CITC, an Egyptian company, supports its main computers at Abbasiya. It also supports the card production centre at the 6 October site. [The interior ministry's Civil Status Sector issues and renews ID cards itself](<https://www.moi.gov.eg/news/GetDetails?newsId=db391b26-33f2-44ab-bd3b-7818d08d6cb7>), through caravans, hotlines and home visits, it said in February 2025.

**Maintained nationally.** [CITC provides technical support, database updating and round-the-clock customer support for the national number project](<https://www.citc.com.eg/National%20ID%20SYSTEM.html>). Its work covers the operating systems, communications and security of the system. It manages the programme groups jointly with Civil Status Organization technicians. CITC published this account in 2024.

**Platform owned.** No source found says the system runs on code the state owns. [CITC's 2024 account covers support and development work for the project](<https://www.citc.com.eg/National%20ID%20SYSTEM.html>). It does not say who holds the code. The account names CITC as the developer of the work.
