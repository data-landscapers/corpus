# Ghana

## Interoperability of education systems

**Education systems exchanging data.** [The Ministry of Education's PMDV Dashboard API documentation lists endpoints serving EMIS school statistics, enrolment rates, schools and NST test scores, and a POST endpoint that takes data from agencies by agency code into MongoDB, with development and production base URLs; it does not say which systems feed it or that it is in service](<https://pmdv.moedatadashboard.com/api_documentation>).

**One learner identifier across education systems.** No source found since October 2023 says one learner identifier is used across education systems. The nearest held fact: [the one given above](<https://pmdv.moedatadashboard.com/api_documentation>).

**Linked to the national ID or another sector.** No source found since October 2023 says learner records are linked to the national ID or another sector. The nearest held fact: [the one given above](<https://pmdv.moedatadashboard.com/api_documentation>).
