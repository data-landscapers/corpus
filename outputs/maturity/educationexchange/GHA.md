# Ghana

## Interoperability of education systems

**Education systems exchanging data.** [In 2024 the Ministry of Education's PMDV Dashboard API documentation listed endpoints serving EMIS school statistics, enrolment rates, schools and NST test scores](<https://pmdv.moedatadashboard.com/api_documentation>). [A further endpoint takes data from agencies by agency code](<https://pmdv.moedatadashboard.com/api_documentation>). [It does not say which systems feed it or that it is in service](<https://pmdv.moedatadashboard.com/api_documentation>).

**One learner identifier across education systems.** No source found since October 2023 says one learner identifier is used across education systems. The nearest fact: [the 2024 dashboard serves school-level statistics and NST test scores](<https://pmdv.moedatadashboard.com/api_documentation>).

**Linked to the national ID or another sector.** No source found since October 2023 says learner records are linked to the national ID or another sector. The nearest fact: [the 2024 dashboard takes data from agencies by agency code](<https://pmdv.moedatadashboard.com/api_documentation>).
