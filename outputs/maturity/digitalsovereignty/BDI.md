# Burundi

## Control of state data

**Rule on state data.** [Iwacu reports](<https://www.iwacu-burundi.org/lia-au-coeur-de-la-strategie-numerique-au-burundi/>) that Burundi's national AI strategy was validated at a workshop in April 2026. The strategy provides for modernising the Setic data center and creating data hubs. It also provides for developing a sovereign cloud. [The strategy validated on 22 April 2026](<https://www.wearetech.africa/fr/fils/actualites/tech/burundi-une-strategie-nationale-de-l-ia-adossee-a-six-piliers>) pairs sovereign cloud solutions with data centre modernisation.
