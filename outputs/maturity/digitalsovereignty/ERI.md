# Eritrea

## Control of state data

**Rule on state data.** No rule on where state data is held was found since 2023. [A UN Economic Commission for Africa profile published in 2022 says Eritrea does not require local data storage](<https://dtri.uneca.org/v1/uploads/country-profile/eri-country-profile-en.pdf>) and sets no requirement on infrastructure.

**Hosted nationally.** No source found says government data or a core system is hosted in a national data centre or cloud. The nearest fact is the new customs system. [The Ministry of Information reported in January 2026 that ASYCUDA World had gone live for customs](<https://shabait.com/2026/01/08/eritrea-launches-landmark-digital-customs-system>), built with the UN Development Programme.

**Contract terms.** [Eritrea's government received the complete source code of ASYCUDA World with the system in January 2026](<https://shabait.com/2026/01/08/eritrea-launches-landmark-digital-customs-system>), the Ministry of Information's Shabait reports. The system was built with the UN Development Programme and runs customs clearance for the country.

***Also on file***. [ASYCUDA World](<https://shabait.com/2026/01/08/eritrea-launches-landmark-digital-customs-system>).

***Not found***. No source found since 2023 says a rule on state data is in force. None says government data is hosted in a national data centre or cloud.
