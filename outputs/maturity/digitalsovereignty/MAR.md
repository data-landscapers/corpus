# Morocco

## Control of state data

**Rule on state data.** Article 11 of Morocco's 2020 cybersecurity law, loi n° 05-20, [requires sensitive data to be hosted only on national territory](<https://www.anrt.ma/sites/default/files/2022-02/loi_05-20_cybersecurite_fr.pdf>). The Cloud 2025-2030 roadmap sets a [Cloud First Policy by circular](<https://leseco.ma/business/strategie-cloud-2025-2030-le-maroc-trace-la-voie-pour-ses-administrations-publiques-video.html>) as the default for public administrations. The draft 2027 finance bill, presented to Parliament on 23 October 2026, [provides for the Jazari-Root sovereign data centre in Rabat](<https://lhybride.ma/briefs/plf-2027-cloud-first-ministere-ia/>) for the state's strategic data. Its presentation note [commits the government to store Moroccans' data in a sovereign national cloud](<https://ladsi.ma/article/plf-2027-maroc-cloud-souverain-formation-ia>) in 2027.

**Hosted nationally.** No source found since October 2023 says government data or a core system is hosted in a national data centre or cloud. The nearest held fact: [the one given above](<https://en.hespress.com/112805-morocco-overtakes-south-africa-as-africas-top-data-center-hub.html>).

**Contract terms.** No source found since October 2023 says a government contract carries terms on data jurisdiction, portability or exit. The nearest held fact: [the one given above](<https://en.hespress.com/112805-morocco-overtakes-south-africa-as-africas-top-data-center-hub.html>).
