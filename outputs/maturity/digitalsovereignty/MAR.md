# Morocco

## Control of state data

**Rule on state data.** [Hespress English, citing a Global Finance report, states that a 2021 law mandates sensitive data be stored locally in Morocco](<https://en.hespress.com/112805-morocco-overtakes-south-africa-as-africas-top-data-center-hub.html>). [The Maroc IA 2030 portfolio presented on 8 September 2026 includes a 50 MW data centre in Rabat associated with a sovereign cloud and a 'Move to Cloud' programme for public administrations](<https://leseco.ma/maroc/maroc-ia-2030-le-royaume-passe-de-lambition-a-laction.html>). In December 2025 the digital transition minister presented a [Cloud 2025-2030 roadmap](<https://www.lavieeco.com/au-royaume/seghrouchni-la-feuille-de-route-cloud-2025-2030-renforce-la-souverainete-numerique-du-royaume/>), with a [Cloud First Policy, set by circular, as the default for public administrations](<https://leseco.ma/business/strategie-cloud-2025-2030-le-maroc-trace-la-voie-pour-ses-administrations-publiques-video.html>) and a [national sovereign cloud for the state's sensitive information systems](<https://telquel.ma/instant-t/2025/12/02/pour-seghrouchni-ladoption-du-cloud-levier-essentiel-pour-la-souverainete-numerique_1963494/>).

**Hosted nationally.** No source found since October 2023 says government data or a core system is hosted in a national data centre or cloud. The nearest held fact: [the one given above](<https://en.hespress.com/112805-morocco-overtakes-south-africa-as-africas-top-data-center-hub.html>).
