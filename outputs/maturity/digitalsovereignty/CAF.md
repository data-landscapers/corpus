# Central African Republic

## Control of state data

**Rule on state data.** [Paradigm Initiative's Londa 2023 report](<https://paradigmhq.org/wp-content/uploads/2024/06/CAR-Londa-Report.pdf>) says the Central African Republic has no stand-alone data protection law or regulation. It has none specifically on biometric databases or on data localisation. It also has no officially recognised national cybersecurity strategy.

**Hosted nationally.** No source found since October 2023 says a national data centre or cloud hosts government data. None says one hosts a core system. The nearest held fact: [a 2024 report finds no rule on data localisation in the Central African Republic](<https://paradigmhq.org/wp-content/uploads/2024/06/CAR-Londa-Report.pdf>).

**Contract terms.** No source found since October 2023 says a government contract carries terms on data jurisdiction, portability or exit. The nearest held fact: [the same report finds no stand-alone data protection law or regulation](<https://paradigmhq.org/wp-content/uploads/2024/06/CAR-Londa-Report.pdf>).
