# Malawi

## Off-site backup for government systems

**A backup site 200 km or more away in service, and for the shared government systems.** [The IDEA progress report for January-June 2026 says resilient telecom links with the disaster recovery site in Blantyre were commissioned for the Government national data centre in Lilongwe, and a redundancy link between the Lilongwe and Blantyre data centres was completed; main site in Lilongwe, backup in Blantyre](<https://idea.comesa.int/wp-content/uploads/2026/10/IDEA-Biannual-implementation-Progress-January-to-June-2026-V-J20-FK-006.pdf>). [The Request for Bids for expanding the National Data Centre describes the existing DR site as a hot site in Blantyre, about 320 km from the production site, mirroring the production site's data over a 10Gbps fibre link; main site place not stated](<https://api.pppc.mw/api/download/722>). These place a backup site 200 km or more from the main one in service for the government's shared systems.

**A recovery plan or test on record.** No source found from the past three years states a recovery plan or a failover test for [the backup site](<https://idea.comesa.int/wp-content/uploads/2026/10/IDEA-Biannual-implementation-Progress-January-to-June-2026-V-J20-FK-006.pdf>).

**Primary and backup both Tier III.** [The terms of reference state that the National Data Centre in Area 4, Lilongwe (primary site) and the disaster-recovery site at Mandala, Blantyre are both Tier-III facilities; the main facility was expected to be fully operational in March 2025; the document is dated January 2025](<https://api.pppc.mw/api/download/647>).
