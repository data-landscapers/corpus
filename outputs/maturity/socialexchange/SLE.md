# Sierra Leone

## Interoperability of social protection systems

**Social protection systems exchanging data.** [The World Bank technical note says the initial SPRINT configuration would upload existing beneficiary and applicant data from current and former programmes, and that a data sharing policy would be developed for exchanges with external entities](<https://documents1.worldbank.org/curated/en/099060123071017741/txt/P1749420c981460708f7206678358ba026.txt>). [The World Bank technical note says the SPRINT module built to import data from external sources had never been used, and that Sierra Leone had no Data Protection Act, so data sharing between agencies carried unmitigated risk](<https://documents1.worldbank.org/curated/en/099060123071017741/txt/P1749420c981460708f7206678358ba026.txt>).

**One registry shared by programmes.** No source found since October 2023 says two or more programmes share one registry. The nearest held fact: [the one given above](<https://documents1.worldbank.org/curated/en/099060123071017741/txt/P1749420c981460708f7206678358ba026.txt>).

**Linked to the ID and another sector.** No source found since October 2023 says the registry is linked to the national ID and to another sector. The nearest held fact: [the one given above](<https://documents1.worldbank.org/curated/en/099060123071017741/txt/P1749420c981460708f7206678358ba026.txt>).
