# Kenya

## Justice

**Case management in service.** Kenya's courts run their registries on the Case Tracking System. [The Judiciary's 2023-24 report says](<https://www.judiciary.go.ke/wp-content/uploads/2024/11/POPULAR-VERSION-SOJAR-REPORT-FY-2023_24.pdf>) it covers case registration, fee assessment, cause lists and court orders. It also helps courts track cases and manage schedules. A Data Tracking Dashboard lets court leaders follow cases from filing to conclusion.

**Online filing.** On 11 March 2024 [e-filing reached all courts](<https://judiciary.go.ke/judiciary-launches-e-filing-in-all-courts-data-tracking-dashboard-and-causelist-portal-portal/>), extended from 17 counties to the other 34. [The Judiciary's report says](<https://www.judiciary.go.ke/wp-content/uploads/2024/11/POPULAR-VERSION-SOJAR-REPORT-FY-2023_24.pdf>) user accounts rose from 7,152 to 51,729. Litigants can file at any hour.

**Open online.** [A Causelist Portal opened the same day](<https://judiciary.go.ke/judiciary-launches-e-filing-in-all-courts-data-tracking-dashboard-and-causelist-portal-portal/>). Anyone, in Kenya or abroad, can find when and where a case is to be heard. Before, a caller had to ring or visit the registry. The portal was launched with e-filing in all courts and a data dashboard.
