# Angola

## Justice

**Case management in service.** Angola's courts had no case system in service on record by 2025. [The 2025 state budget report](<https://www.opais.ao/politica/tribunais-arrancam-com-digitalizacao-de-processos-para-conferir-maior-celeridade/>) said the common-jurisdiction courts would start an integrated information and document system that year. It gave the judicial council over Kz 1 billion for it. No later source says the system went live in any court. The project sits in the Executive's report annexed to the budget.

**Online filing.** No source since November 2023 says cases can be filed online. The nearest fact is [the system planned for 2025](<https://www.opais.ao/politica/tribunais-arrancam-com-digitalizacao-de-processos-para-conferir-maior-celeridade/>), which digitises court documents. The system is meant to dematerialise court documents and manage case information.

**Open online.** No source since November 2023 says judgments or case status are online. The nearest fact is [the same 2025 budget line](<https://www.opais.ao/politica/tribunais-arrancam-com-digitalizacao-de-processos-para-conferir-maior-celeridade/>). The judicial council, the CSMJ, holds the funds for it.

***Also on file***. None found.

***Not found***. No source found since November 2023 says a court case management system is in service in any court.
