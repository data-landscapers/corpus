# Liberia

## Use of open data

**Data published for download, and under an open licence.** [The EITI validation report says LEITI's online Data Portal has significantly improved the openness of extractive data, and that the LEITI Data Warehouse provides production and export data disaggregated by company](<https://eiti.org/documents/liberia-2026-validation-report>). [The LISGIS microdata catalogue lists the anonymised Liberia Annual Agricultural Survey 2024 household dataset as a Public Use File accessible to all for statistical and research purposes, released as version 1.0 (record last modified 1 July 2026); redistribution needs LISGIS written agreement, so no open licence is stated](<https://microdata.lisgislr.org/index.php/catalog/43>). No source found states an open licence; a later answer places the country above that step.

**Several public bodies publishing.** [The EITI validation report names two public data sources providing production and export data by company, the LEITI Data Warehouse and the Ministry of Mines and Energy's online cadastre](<https://eiti.org/documents/liberia-2026-validation-report>).
