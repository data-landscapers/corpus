# DR Congo

## Data localisation rule

**Rule in force.** The Democratic Republic of the Congo's rule covers the state's own data. In the ministry's report of a ministerial visit on 24 July 2025, an official says [the telecommunications law requires all public administration data to be hosted in the government data centre in Kinshasa-Gombe](<https://sgptntic.gouv.cd/transition-numerique-le-ministre-augustin-kibassa-maliba-visite-le-data-center-du-gouvernement/>). The report does not give the law's date or the article. The same account says some public data still sat on private servers at that date.

**Enforcer named and rule applied.** The nearest held fact is that account, which [states the hosting duty](<https://sgptntic.gouv.cd/transition-numerique-le-ministre-augustin-kibassa-maliba-visite-le-data-center-du-gouvernement/>) and names no body that checks it. No source found names a body that checks compliance with the rule or grants exemptions from it. No source found names or counts the public bodies that have moved their data to the government data centre, and none reports an order or penalty.
