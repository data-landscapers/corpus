# Botswana

## Data localisation rule

**Rule in force.** Botswana's rule is a copy requirement. A report of November 2025 says the Data Protection Act has been in effect since January 2025. It says the Act [allows data to be transferred abroad only to approved countries and requires a copy of the data to remain in Botswana](<https://www.mmegi.bw/business/govt-moves-to-in-house-local-data/news>). The same report says the Act was at first intended to go further and compel businesses to store data in the country. It says the minister still intends that.

**Enforcer named and rule applied.** The same report [describes the copy requirement and the limits on which countries may host data](<https://www.mmegi.bw/business/govt-moves-to-in-house-local-data/news>). It does not say who checks them. No source found names a body that checks compliance with the rule or grants exemptions from it. No order, penalty or exemption under the copy requirement has been found. No count of organisations that keep a copy in the country has been found.

***Also on file***. [Delta Digital Data Centre](<https://www.mmegi.bw/business/govt-moves-to-in-house-local-data/news>); [Botswana adequacy list](<https://dial.global/africas-digital-future-seamless-data-flows/>).

***Not found***. No source found names a body that enforces the rule. No regulator, agency or ministry unit has been found that checks compliance or grants exemptions.
