# Benin

## Data localisation rule

**Rule in force.** Benin's rule sits in its digital code. The president of the data protection authority, the APDP, spoke at the Africa Digital Expo in Cotonou on 21 October 2026. He said [the Code numérique requires critical servers to be sited on national territory](<https://www.agenceecofin.com/actualites-numerique/2210-142651-adex-2026-mtn-benin-plaide-pour-une-cyber-resilience-proactive-a-lere-de-la-5g>). He called local storage of data a security imperative and asked for the code to be applied rigorously. He spoke of the rule as one already binding. He gave no date for it and no list of the servers it covers.

**Enforcer named and rule applied.** The APDP president [called for rigorous application of the Code numérique](<https://www.agenceecofin.com/actualites-numerique/2210-142651-adex-2026-mtn-benin-plaide-pour-une-cyber-resilience-proactive-a-lere-de-la-5g>). He made the call in a plea for the data protection authority, the cybersecurity agency and the telecoms regulator, ARCEP, to regulate together. He did not say which of them checks that critical servers stay in Benin. He named no organisation ordered to move its servers or exempted.
