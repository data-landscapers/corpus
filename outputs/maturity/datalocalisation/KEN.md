# Kenya

## Data localisation rule

**Rule in force.** Kenya's rule covers the state's most sensitive data. [Guidelines to the 2025 Kenya Cloud Policy, reported in August 2026, require top secret State data to be held in Kenya](<https://www.businessdailyafrica.com/bd/corporate/technology/search-for-firm-to-host-sensitive-state-data-on-cloud-begins-5549208>). [State entities may not host data in their own server rooms without a Cloud Adoption Committee's consent](<https://www.businessdailyafrica.com/bd/corporate/technology/search-for-firm-to-host-sensitive-state-data-on-cloud-begins-5549208>). [They have 24 months to migrate](<https://www.businessdailyafrica.com/bd/corporate/technology/search-for-firm-to-host-sensitive-state-data-on-cloud-begins-5549208>). [A draft AI and Emerging Technologies Policy, out for comment since July 2026, would keep sensitive public datasets in Kenya](<https://cioafrica.co/ai-governance-fragmentation-cause-for-concern/>).

**Enforcer named and rule applied.** The nearest held fact is the same report, which [names a Cloud Adoption Committee that authorises exceptions to the bar on in-house server rooms](<https://www.businessdailyafrica.com/bd/corporate/technology/search-for-firm-to-host-sensitive-state-data-on-cloud-begins-5549208>). It does not say that the committee, or any other body, checks where top secret data is held. No source found names a body that checks compliance with the rule or grants exemptions from it. No source found counts the State entities that have moved.
