# Kenya

## Data localisation rule

**Rule in force.** Kenya's rule covers the state's most sensitive data. A report of 6 August 2026 says the implementation guidelines of the 2025 Kenya Cloud Policy, published by the Ministry of ICT and the Digital Economy, [require top secret State data to be held in a data centre within Kenya](<https://www.businessdailyafrica.com/bd/corporate/technology/search-for-firm-to-host-sensitive-state-data-on-cloud-begins-5549208>). They also bar State entities from hosting data in their own server rooms without the authorisation of a Cloud Adoption Committee, and give them 24 months to migrate.

**Enforcer named and rule applied.** The nearest held fact is the same report, which [names a Cloud Adoption Committee that authorises exceptions to the bar on in-house server rooms](<https://www.businessdailyafrica.com/bd/corporate/technology/search-for-firm-to-host-sensitive-state-data-on-cloud-begins-5549208>). It does not say that the committee, or any other body, checks where top secret data is held. No source found names a body that checks compliance with the rule or grants exemptions from it. No source found counts the State entities that have moved.
