# Togo

## In-house capacity

**Government staff.** No source found from 2023 or later says government staff run a named system. [The digitalisation framework](<https://ressources.digital.gouv.tg/shares/documentations/Cadre_de_digitalisation_des_services_publics/html/gouvernance.html>) assigns roles, not running systems.

**A technology body for government.** [The digitalisation framework gives Agence Togo Digital a role in deploying solutions for public services](<https://ressources.digital.gouv.tg/shares/documentations/Cadre_de_digitalisation_des_services_publics/html/gouvernance.html>). It also has the agency supply low-code platforms to the integrators that public bodies hire.

**Built in-house.** No source found says a system built by government staff went live since October 2023. [The framework](<https://ressources.digital.gouv.tg/shares/documentations/Cadre_de_digitalisation_des_services_publics/html/gouvernance.html>) leaves building to integrators.

**Systems run wholly in-house.** No source found since October 2023 names a system run wholly by government staff. [The framework](<https://ressources.digital.gouv.tg/shares/documentations/Cadre_de_digitalisation_des_services_publics/html/gouvernance.html>) names none.
