# Mozambique

## In-house capacity

**Government staff.** [INAGE, Mozambique's national e-government institute, states it developed the CloudGov file storage and sharing system for use across public administration institutions (2020, before the three-year window)](<https://www.inage.gov.mz/?p=2697>).

**A technology body for government.** [INAGE's service catalogue, retrieved 2026-08-08, lists server rental, application hosting, application development and government network connection (GovNET, MoRENet) as services for public bodies](<https://www.inage.gov.mz/?p=2697>).

**Built in-house.** [INAGE states it recently developed CloudGov and that it is in the implementation phase across institutions, with no go-live date given (2020, before the three-year window)](<https://www.inage.gov.mz/?p=2697>).

**A career structure for IT staff.** No source held says the government has adopted an ICT cadre, a scheme of service or an establishment for its IT staff; the stage rests on [the source that sets it](<https://www.inage.gov.mz/?p=2697>).

***Noted, not assessed***. [Huawei-built data centre (Mozambique)](<https://africachinainitiative.georgetown.edu/research-working-group/blog-posts/huawei-helping-or-hindering-african-countries-secure-their-data-sovereignty-2/>).

***Not held***. No source held says a system built by government staff went live since October 2023.
