# Morocco

## In-house capacity

**Government staff.** The national police's information systems directorate [has digital, development, systems and security teams that run the Epolice platform](<https://fr.le360.ma/societe/plateforme-epolice-comment-la-dgsn-amorce-sa-transformation-digitale-pour-etre-au-plus-pres-et-en_KBP6WMVA5ZF3ZLZRDOTOE3GSDI/>). Le360 reported this in January 2025.

**A technology body for government.** No source found from 2023 or later says a government body builds or runs systems for the rest of government. [The police's own directorate runs Epolice](<https://fr.le360.ma/societe/plateforme-epolice-comment-la-dgsn-amorce-sa-transformation-digitale-pour-etre-au-plus-pres-et-en_KBP6WMVA5ZF3ZLZRDOTOE3GSDI/>) for the police alone. No ministry, agency or state company is found hosting or building systems for other ministries.

**Built in-house.** [Epolice was launched in December 2024](<https://fr.le360.ma/societe/plateforme-epolice-comment-la-dgsn-amorce-sa-transformation-digitale-pour-etre-au-plus-pres-et-en_KBP6WMVA5ZF3ZLZRDOTOE3GSDI/>). The police's own teams built and run it, and no contractor is named.

**Systems run wholly in-house.** No source found names three systems run wholly by government staff. [Epolice is the one found](<https://fr.le360.ma/societe/plateforme-epolice-comment-la-dgsn-amorce-sa-transformation-digitale-pour-etre-au-plus-pres-et-en_KBP6WMVA5ZF3ZLZRDOTOE3GSDI/>), built and run by the police's own teams.

***Also on file***. None found.

***Not found***. No government body is found building or running systems for the rest of government since 2023.
