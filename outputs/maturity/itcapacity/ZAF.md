# South Africa

## In-house capacity

**Government staff.** [The Electoral Commission's ICT department is stated to run its ICT environment, on VMware as the core virtualisation platform, for which it seeks licence renewal](<https://www.itweb.co.za/article/top-ict-tenders-iec-targets-tech-upgrades-renewals/Pero3MZ31YYqQb6m>). [The Road Accident Fund seeks a service provider for end-to-end monitoring, detection and response on its existing in-house Microsoft Sentinel threat-detection solution (five years)](<https://www.itweb.co.za/article/top-ict-tenders-sita-sees-activity-surge/lwrKx73YyZRqmg1o>). [The Electoral Commission is re-advertising for redevelopment of its mobile app, saying the framework is outdated and insecure](<https://www.itweb.co.za/article/top-ict-tenders-iec-targets-tech-upgrades-renewals/Pero3MZ31YYqQb6m>).

**A technology body for government.** [The communications minister's written reply to Parliament states the State IT Agency (SITA) delivered 117 e-services through 35 digital products to more than 30 government departments and public entities in 2025/26](<https://pmg.org.za/committee-question/41100/>).

**Built in-house.** [The Electoral Commission's public mobile app was originally built in-house for the 2019 elections, with updates in 2021 and 2024 (2019, before the three-year window)](<https://www.itweb.co.za/article/top-ict-tenders-iec-targets-tech-upgrades-renewals/Pero3MZ31YYqQb6m>).

**Systems run wholly in-house.** No source found since October 2023 says government staff run, maintain or built a named system with no contractor doing the work; the stage rests on [the source that sets it](<https://pmg.org.za/committee-question/41100/>).
