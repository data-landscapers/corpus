# Rwanda

## In-house capacity

**Government staff.** [RISA, the state information society authority, runs the support centre for the shared government website platform](<https://archive.fosdem.org/2024/events/attachments/fosdem-2024-3730-collaborative-government-websites-standardization-for-digital-sovereignty-using-open-source-the-model-of-rwanda-and-the-govstack-global-initiative/slides/22785/Collaborative_Gov_Websites_-_FOSDEM_2024_1_EY4bKnz.pdf>). More than 300 government websites run on it.

**A technology body for government.** [RISA serves the whole of government through that platform](<https://archive.fosdem.org/2024/events/attachments/fosdem-2024-3730-collaborative-government-websites-standardization-for-digital-sovereignty-using-open-source-the-model-of-rwanda-and-the-govstack-global-initiative/slides/22785/Collaborative_Gov_Websites_-_FOSDEM_2024_1_EY4bKnz.pdf>). Its support centre handles both functional and technical help.

**Built in-house.** No source found since October 2023 says a system built by government staff went live. [The website platform's support centre was running by early 2024](<https://archive.fosdem.org/2024/events/attachments/fosdem-2024-3730-collaborative-government-websites-standardization-for-digital-sovereignty-using-open-source-the-model-of-rwanda-and-the-govstack-global-initiative/slides/22785/Collaborative_Gov_Websites_-_FOSDEM_2024_1_EY4bKnz.pdf>), but its launch date is not given.

**Systems run wholly in-house.** No source found since October 2023 names three systems run wholly by government staff. [The website platform is the one named](<https://archive.fosdem.org/2024/events/attachments/fosdem-2024-3730-collaborative-government-websites-standardization-for-digital-sovereignty-using-open-source-the-model-of-rwanda-and-the-govstack-global-initiative/slides/22785/Collaborative_Gov_Websites_-_FOSDEM_2024_1_EY4bKnz.pdf>). The slides present it as a shared open-source model for government websites.
