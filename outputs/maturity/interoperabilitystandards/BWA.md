# Botswana

## Technical standards for government systems

**Standards published.** Botswana's interoperability framework and standards are being revised. [Expertise France's project page of 17 February 2026](<https://www.expertisefrance.fr/en/projects/digital-transformation-botswana>) says its project, funded by the European Union and running from August 2024 to August 2027, works with ESTDEV to improve and align Botswana's national interoperability framework, standards, guidelines and tools. The page lists a harmonised and operational national interoperability framework for e-government services as a result the project expects to deliver. It does not say the framework has been adopted or issued.

**Standards required and checked.** [The same project page](<https://www.expertisefrance.fr/en/projects/digital-transformation-botswana>) describes the work as under way. The project has until August 2027 to deliver the harmonised framework for e-government services that it lists as its expected result, together with the standards, guidelines and tools aligned to it.

***Also on file***. [Framework for Secure Exchange of Information](<http://www.bocra.org.bw/sites/default/files/sites/default/files/documents/digital_services_ACT.pdf>), an interoperability framework that no source found says sets technical standards.

***Not found***. No source found says the standards have been published.
