# Zimbabwe

## Technical standards for government systems

**Standards published.** Zimbabwe is building a government enterprise architecture that is to carry interoperability standards. A Herald column of November 2026 says the government is [building a whole-of-government enterprise architecture](<https://www.heraldonline.co.zw/transforming-public-services-through-one-digital-ecosystem/>). The column says the architecture defines interoperability standards, digital identity management, data governance and cybersecurity requirements. It names common data standards and secure application interfaces as what would let government systems communicate. It names no standard that has been issued.

**Standards required and checked.** The same [Herald column](<https://www.heraldonline.co.zw/transforming-public-services-through-one-digital-ecosystem/>) describes the architecture as work under way. It names no instrument making the standards compulsory. It names no system checked against them. The column cites the tax system's links to the companies registry, the deeds office and the civil registry as a base to build on.

***Also on file***. [Enterprise Architecture Model blueprint](<https://techreviewafrica.com/news/5347/zimbabwe-pushes-smart-government-agenda-with-new-digital-blueprint>), an interoperability framework that no source found says sets technical standards. [Government enterprise architecture framework](<https://ega.ee/project/enterprise-architecture-zimbabwe/>), likewise. [Ndarama ERP](<https://spikedmedia.co.zw/zimbabwe-bets-on-digital-gold-inside-the-launch-of-ndarama-and-the-push-for-ai-sovereignty/>). [National Interoperability Platform](<https://apai-crvs.uneca.org/sites/default/files/resourceuploads/day-2-interoperability-zimbabwe.pdf>).

***Not found***. No source found says the standards have been issued, or that public bodies are required to use them.
