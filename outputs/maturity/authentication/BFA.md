# Burkina Faso

## Authentication

**Authentication service.** [Cybastion says it is leading implementation of electronic signature through Burkina Faso's public key infrastructure, with the platform installed and about thirty people, including ANSSI staff, trained on it on 28-30 April 2025](<https://prod.cybastiontech.com/blog/newsroom-4/cybastion-trains-the-it-teams-of-the-government-of-burkina-faso-in-the-electronic-signature-system-348>). [Digital Magazine reports that ANSSI, with US firm Cybastion, opened a scoping workshop on 30 September 2024 for a national public key infrastructure with root and issuing certification authorities and remote electronic signature, implementation set for December 2025](<https://digitalmagazine.bf/2024/10/04/le-burkina-faso-lance-un-projet-ambitieux-dinfrastructure-a-cles-publiques-pour-renforcer-la-securite-les-echanges-en-ligne/>).
