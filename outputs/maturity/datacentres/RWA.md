# Rwanda

## Data centres for hire in service

**In service, Tier III, and two of them.** [Xalam Analytics estimates about 4 live commercial data centre facilities in Rwanda in 2025, with about 1MW live IT load and about 70% occupancy by third-party customers; facilities are small (20-80 racks) and mostly hybrid, leasing excess capacity to external customers; none are named](<https://cms.d4dhub.eu/assets/Initiatives/Data-Governance-in-Africa/Digital-Investment-Facility/Data-Center-Market-Briefs-Rwanda-2026.pdf>). [TransAfrica Communications (TrAC), a Rwanda-based ISP, is stated to offer data centre collocation services to customers (no facility named, no tier given)](<https://aka-partners.com/insight-and-news/>). [Liquid Intelligent Technologies Rwanda (Liquid Intelligent Technologies Rwanda), colocation/carrier-neutral, in service](<https://www.cassavatechnologies.com/cassava-to-upgrade-its-data-centres-with-nvidia-supercomputers-to-drive-africas-ai-future/>). These place a data centre for hire in service, which answers the first of the study's four questions. No source found states one at Tier III or above: built so that power and cooling can be maintained without shutting the data centre down, as the Uptime Institute defines it. Capacity is given where a source states it; it sets no stage.

**A global cloud region.** Nothing found says a global cloud provider runs a region beside [the data centres](<https://cms.d4dhub.eu/assets/Initiatives/Data-Governance-in-Africa/Digital-Investment-Facility/Data-Center-Market-Briefs-Rwanda-2026.pdf>). Only a live region of a public cloud provider answers this question; an announced region, a content cache or an edge site does not.
