# Lesotho

## Data centres for hire in service

**In service, Tier III, and two of them.** [Vodacom Lesotho's business page offers colocation in purpose-built data centres across the country and says its One Connect service is hosted in its two data centres at Maseru West and Lekokoaneng](<https://www.vodacom.co.ls/business/fixed-solutions/>). [Vodacom Lekokoaneng Data Center (Vodacom Business / Vodacom Lesotho), colocation/carrier-neutral, in service](<https://www.datacenterdynamics.com/en/news/vodacom-opens-data-center-in-maputo-mozambique>). These place a data centre for hire in service, which answers the first of the study's four questions. No source found states one at Tier III or above: built so that power and cooling can be maintained without shutting the data centre down, as the Uptime Institute defines it. Capacity is given where a source states it; it sets no stage.

**A global cloud region.** Nothing found says a global cloud provider runs a region beside [the data centres](<https://www.vodacom.co.ls/business/fixed-solutions/>). Only a live region of a public cloud provider answers this question; an announced region, a content cache or an edge site does not.
