# Uganda

## Data centres for hire in service

**In service, Tier III, and two of them.** [Raxio Group states that Raxio UG1 in Namanve is Uptime Institute Tier III certified](<https://www.raxiogroup.com/data-centres/uganda/>). [ITWeb reports that all Raxio's data centres, Uganda's included, are Tier III certified](<https://itweb.africa/article/raxio-raises-data-centre-funding/8OKdWMDX2zVMbznQ>). [Raxio UG1 sells carrier-neutral colocation](<https://www.raxiogroup.com/raxio-tops-us380-million-in-committed-capital-as-roha-and-meridiam-boost-stakes-amid-sixfold-growth-surge-for-its-african-data-centres/>). [In July 2026 Raxio said it runs Tier III carrier-neutral facilities in Uganda](<https://tech.africa/raxio-380m-committed-capital/>). [Xalam Analytics counted about five commercial data centres leasing space to others in Uganda in 2024](<https://cms.d4dhub.eu/assets/Initiatives/Data-Governance-in-Africa/Digital-Investment-Facility/2507_Country-Market-Briefs/Data-Center-Market-Brief-Uganda.pdf>). [It names Raxio's as the largest and the only carrier-neutral one](<https://cms.d4dhub.eu/assets/Initiatives/Data-Governance-in-Africa/Digital-Investment-Facility/2507_Country-Market-Briefs/Data-Center-Market-Brief-Uganda.pdf>). These place a data centre for hire at Tier III or above in service. A second at Tier III is not stated. Capacity is given where a source states it; it sets no stage.

**A global cloud region.** Nothing found says a global cloud provider runs a region beside [the data centres](<https://www.raxiogroup.com/data-centres/uganda/>). Only a live region of a public cloud provider answers this question; an announced region, a content cache or an edge site does not.
