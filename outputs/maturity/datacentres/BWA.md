# Botswana

## Data centres for hire in service

**In service, Tier III, and two of them.** [Mascom's CEO states the Mascom Innovation Centre data centre is Tier III certified internationally (operator statement; certifier not named)](<https://businessweekly.co.bw/companies-markets/mascoms-strategic-shift-from-internal-need-to-market-opportunity>). [DCD describes the newly launched Digital Delta Data Center (BoFiNet, Gaborone) as Tier-III certified without naming the certifier](<https://www.datacenterdynamics.com/en/news/botswana-launches-first-national-data-center/>). [ITWeb Africa, citing BoFiNet, describes the Digital Delta Data Centre (DDDC), run by BoFiNet, as the state's first and only Uptime Institute Tier III-certified, carrier-neutral facility of its scale](<https://itweb.africa/article/bofinet-launches-digital-delta-ixp/8OKdWMDXL9VMbznQ>). [Mascom's Innovation Centre data centre is open to external customers and sells colocation, cloud, IaaS, disaster recovery and managed services, per Mascom's CEO](<https://businessweekly.co.bw/companies-markets/mascoms-strategic-shift-from-internal-need-to-market-opportunity>). [Digital Delta Data Centre (DDDC) (Botswana Fibre Networks Ltd (BoFiNet)), colocation/carrier-neutral, in service](<https://techafricanews.com/2026/03/18/botswana-advances-digital-government-with-1gov-1citizen-platform-upgrade/>). Together these place two data centres for hire at Tier III or above in service, which answers the first three of the study's four questions. Capacity is given where a source states it; it sets no stage.

**A global cloud region.** Nothing found says a global cloud provider runs a region beside [the data centres](<https://businessweekly.co.bw/companies-markets/mascoms-strategic-shift-from-internal-need-to-market-opportunity>). Only a live region of a public cloud provider answers this question; an announced region, a content cache or an edge site does not.
