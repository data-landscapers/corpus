# Madagascar

## Data centres for hire in service

**In service, Tier III, and two of them.** [STELLARIX offers colocation (1U to full 42U racks, carrier-neutral, Smart Hands) from two data centres in Antananarivo, Galaxy Andraharo and Analakely, advertised at 99.982% availability](<https://www.stellar-ix.com/solutions/colocation/housing/>). [Xalam Analytics estimates Madagascar had about 2 live commercial (colocation, third-party lease) data centre facilities in 2024 with 1.4 MW live critical IT load, about 40% occupied and about 100% carrier-neutral; facilities are not named](<https://cms.d4dhub.eu/assets/Initiatives/Data-Governance-in-Africa/Digital-Investment-Facility/2507_Country-Market-Briefs/Data-Center-Market-Brief-Madagascar.pdf>). These place a data centre for hire in service, which answers the first of the study's four questions. No source found states one at Tier III or above: built so that power and cooling can be maintained without shutting the data centre down, as the Uptime Institute defines it. Capacity is given where a source states it; it sets no stage.

**A global cloud region.** Nothing found says a global cloud provider runs a region beside [the data centres](<https://www.stellar-ix.com/solutions/colocation/housing/>). Only a live region of a public cloud provider answers this question; an announced region, a content cache or an edge site does not.
