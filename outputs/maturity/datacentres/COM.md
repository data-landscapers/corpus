# Comoros

## Data centres for hire in service

**In service, Tier III, and two of them.** [Comores Câbles states that its data centre offers secure, scalable data-management and hosting solutions to businesses of all sizes (99.9% availability, 10 Gbps data centre bandwidth); the same page says a separate neutral data centre is still under construction](<https://www.comorescables.km/Technologies>). These place a data centre for hire in service, which answers the first of the study's four questions. No source found states one at Tier III or above: built so that power and cooling can be maintained without shutting the data centre down, as the Uptime Institute defines it. Capacity is given where a source states it; it sets no stage.

**A global cloud region.** Nothing found says a global cloud provider runs a region beside [the data centres](<https://www.comorescables.km/Technologies>). Only a live region of a public cloud provider answers this question; an announced region, a content cache or an edge site does not.
