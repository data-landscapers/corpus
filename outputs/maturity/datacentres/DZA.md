# Algeria

## Data centres for hire in service

**In service, Tier III, and two of them.** [Iconsnet operates two data centres, in Algiers and Oran, offering cloud computing and off-site backup](<https://www.jeune-independant.net/centre-national-des-services-numeriques-le-coeur-digital-de-letat-prend-vie/>). [DZWatch reports the inauguration of the I-Cloud sovereign data centre in the Akbou industrial zone (Bejaia), presided by the Knowledge Economy Minister, offering cloud hosting and computing to startups and SMEs](<https://dzwatch.dz/akbou-inaugurates-nations-first-100-sovereign-data-center/>). [Algerie360's interview with AYRADE's founder describes AYRADE as a sovereign cloud operator with 3,700 active cloud customers and two operational data centres on national territory (facilities not named)](<https://www.algerie360.com/ayrade-a-la-bourse-dalger-entretien-avec-son-fondateur-mohamed-lamine-belbachir/>). [ICOSNET Algiers DATA CENTER (ICOSNET), colocation/carrier-neutral, in service](<https://icosnet.com.dz/en/legal-pensions/>). These place a data centre for hire in service, which answers the first of the study's four questions. No source held states one at Tier III or above: built so that power and cooling can be maintained without shutting the data centre down, as the Uptime Institute defines it. Capacity is given where a source states it; it sets no stage.

**A global cloud region.** Nothing held says a global cloud provider runs a region beside [the data centres](<https://www.jeune-independant.net/centre-national-des-services-numeriques-le-coeur-digital-de-letat-prend-vie/>). Only a live region of a public cloud provider answers this question; an announced region, a content cache or an edge site does not.
