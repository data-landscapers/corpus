# Somalia

## Data centres for hire in service

**In service, Tier III, and two of them.** [Dalkom Somalia says it offers colocation hosting to business customers from its own data centres in Mogadishu and Nairobi](<https://www.dalkomsomalia.com/managed-national.php?id=187>). These place a data centre for hire in service, which answers the first of the study's four questions. No source found states one at Tier III or above: built so that power and cooling can be maintained without shutting the data centre down, as the Uptime Institute defines it. Capacity is given where a source states it; it sets no stage.

**A global cloud region.** Nothing found says a global cloud provider runs a region beside [the data centres](<https://www.dalkomsomalia.com/managed-national.php?id=187>). Only a live region of a public cloud provider answers this question; an announced region, a content cache or an edge site does not.
