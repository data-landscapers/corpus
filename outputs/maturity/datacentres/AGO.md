# Angola

## Data centres for hire in service

**In service, Tier III, and two of them.** [Raxio says its Luanda carrier-neutral data centre is Tier III certified, the first independent carrier-neutral one in Angola to be so](<https://techafricanews.com/2026/07/23/raxio-and-afr-ix-partner-to-boost-digital-connectivity-in-angola-and-mozambique/>). [Paratus Group says its two existing Luanda data centres are Tier III by design (operator statement); the facilities are not named individually](<https://paratus.africa/blog/paratus-group-secures-funding-for-infrastructure-expansion-projects/>). [Raxio Group operates carrier-neutral colocation data centres in Luanda that host customers, and AFR-IX Telecom is deploying into them](<https://techafricanews.com/2026/07/23/raxio-and-afr-ix-partner-to-boost-digital-connectivity-in-angola-and-mozambique/>). [Raxio says all its data centres, Angola's included, are Tier III certified](<https://itweb.africa/article/raxio-raises-data-centre-funding/8OKdWMDX2zVMbznQ>). [Raxio Group, a carrier-neutral colocation operator, says it operates a data centre in Angola (among six countries)](<https://itweb.africa/article/raxio-raises-data-centre-funding/8OKdWMDX2zVMbznQ>). [Raxio Angola AG1 (Raxio Group), colocation/carrier-neutral, in service, Tier III or above on the operator's own statement](<https://www.raxiogroup.com/raxio-tops-us380-million-in-committed-capital-as-roha-and-meridiam-boost-stakes-amid-sixfold-growth-surge-for-its-african-data-centres/>). [Paratus Angola (previously ITA) opened DC2 in Luanda in 2019](<https://www.datacenterdynamics.com/en/news/paratus-group-to-build-third-angola-data-center/>). Together these place two data centres for hire at Tier III or above in service, which answers the first three of the study's four questions. Capacity is given where a source states it; it sets no stage.

**A global cloud region.** Nothing found says a global cloud provider runs a region beside [the data centres](<https://techafricanews.com/2026/07/23/raxio-and-afr-ix-partner-to-boost-digital-connectivity-in-angola-and-mozambique/>). Only a live region of a public cloud provider answers this question; an announced region, a content cache or an edge site does not.
