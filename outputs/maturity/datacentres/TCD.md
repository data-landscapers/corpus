# Chad

## Data centres for hire in service

**In service, Tier III, and two of them.** [Millicom announced the launch of its new 126-rack data centre in N'Djamena for Tigo Chad, with close to 1 MW total power load, serving B2B customers](<https://innovation-village.com/millicom-reveals-data-centre-plans-chad-senegal/>). [Tigo Tchad (Millicom) inaugurated its data centre in N'Djamena on 21 June 2016 and offers rack space for rent to businesses to host their data; Tigo states it is a modular facility costing over FCFA 3 billion](<https://www.osiris.sn/tigo-apporte-la-haute-technologie-au-tchad-avec-l-inauguration-d-un-data-center.html>). [Flexenclosure constructed Chad's first data center, a communications and colocation centre for Tigo in N'Djamena (374 sq m, 400 kW IT load)](<https://www.datacenterdynamics.com/en/news/chad-gets-first-data-center-built-by-flexenclosure/>). These place a data centre for hire in service, which answers the first of the study's four questions. No source found states one at Tier III or above: built so that power and cooling can be maintained without shutting the data centre down, as the Uptime Institute defines it. Capacity is given where a source states it; it sets no stage.

**A global cloud region.** Nothing found says a global cloud provider runs a region beside [the data centres](<https://innovation-village.com/millicom-reveals-data-centre-plans-chad-senegal/>). Only a live region of a public cloud provider answers this question; an announced region, a content cache or an edge site does not.
