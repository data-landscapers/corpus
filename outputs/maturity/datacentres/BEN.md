# Benin

## Data centres for hire in service

**In service, Tier III, and two of them.** [An ASIN official says Benin has several data centres, including one operated commercially by the Société béninoise des infrastructures numériques (SBIN)](<https://cio-mag.com/souverainete-et-cloud-le-benin-face-aux-enjeux-de-lhebergement-des-donnees/>). [ST DIGITAL, a pan-African data-centre operator, says it has infrastructure and sites deployed in Bénin among seven countries serving banks, telecoms operators, administrations and enterprises](<https://st.digital/en/blog/st-digital-s-blog-1/st-digital-526>). [Isocel Telecom Datacenter (Isocel Telecom), colocation/carrier-neutral, in service](<https://www.ajmanchamber.ae/media/archives/en/1/5/ISOCEL_TELECOM_-_Company_Profile_3.pdf>). [MTN Bénin's own product page offers businesses rental of servers and storage at its MTN Data Center, with redundant SBEE, generator and UPS power](<https://www.mtn.bj/business/connectivite/data-center/>). These place a data centre for hire in service, which answers the first of the study's four questions. No source found states one at Tier III or above: built so that power and cooling can be maintained without shutting the data centre down, as the Uptime Institute defines it. Capacity is given where a source states it; it sets no stage.

**A global cloud region.** Nothing found says a global cloud provider runs a region beside [the data centres](<https://cio-mag.com/souverainete-et-cloud-le-benin-face-aux-enjeux-de-lhebergement-des-donnees/>). Only a live region of a public cloud provider answers this question; an announced region, a content cache or an edge site does not.
