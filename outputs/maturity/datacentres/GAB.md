# Gabon

## Data centres for hire in service

**In service, Tier III, and two of them.** On 3 July 2026 [Gabon's first national data centre, run by ST Digital, opened at Nkok](<https://depeches241.com/?p=29457>). It hosts the data of the state, firms and citizens. [TechAfrica News says it was built to Tier III international standards](<https://techafricanews.com/2026/07/06/gabon-inaugurates-first-tier-iii-datacenter-to-boost-digital-sovereignty/>). [The digital economy ministry calls it the Nkok Sovereign Tier III Datacenter](<https://agpgabon.ga/gabon-numerique-le-pays-sa-candidature-au-conseil-de-lunion-internationale-des-telecommunications/>), as does [Gabon's statement for the ITU Council](<https://techafricanews.com/2026/09/03/gabon-presents-its-candidacy-for-the-international-telecommunication-union-itu-council/>). The head of the data protection authority says [the centre, with a mirror site in Haut-Ogooué, was authorised after an impact study](<https://union.sonapresse.com/fr/joel-dominique-ledaga-pour-echanger-directement-avec-meta-tiktok-ou-instagram-il-faut-une-reponse>). A second centre at Tier III is not stated.

**A global cloud region.** Nothing found says a global cloud provider runs a region beside [the data centres](<https://agpgabon.ga/gabon-numerique-le-pays-sa-candidature-au-conseil-de-lunion-internationale-des-telecommunications/>). Only a live region of a public cloud provider answers this question; an announced region, a content cache or an edge site does not.
