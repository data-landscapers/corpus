# Djibouti

## Data centres for hire in service

**In service, Tier III, and two of them.** [The operator, Wingu.Africa, describes the newly launched T07 Technology Park data centre in Djibouti as a Tier 3 certified data centre; the certifying body is not named](<https://africa.hyperscalers.news/news/wingu-africa-launches-tier-iii-data-center-in-djibouti/>). [Djibouti Telecom's own page, as summarised in the capture's header, describes a Tier-3 data centre (DDC) with colocation, operator-stated rather than certified; the page body shown names the Ras Dika data centre](<https://international.djiboutitelecom.dj/>). [TechCabal names the Djibouti Data Centre as a carrier-neutral facility in Djibouti, in a country it calls a Tier 3 carrier-neutral hub](<https://techcabal.com/2026/01/07/how-ethiopia-somalia-and-djibouti-building-africas-digital-powerhouses/>). [Djibouti Data Center (DDC) (Djibouti Data Center SARL), colocation/carrier-neutral, in service](<https://www.state.gov/wp-content/uploads/2025/09/638719_2025-Djibouti-Investment-Climate-Statement.pdf>). [Biometric Update, reporting Wingu Africa's announcement, says Wingu recently launched its second site in Djibouti, housing the country's first integrated cable landing station and data center](<https://www.biometricupdate.com/202506/60m-to-speed-up-digital-connectivity-infrastructure-in-ethiopia-djibouti-tanzania>). Together these place two data centres for hire at Tier III or above in service, which answers the first three of the study's four questions. Capacity is given where a source states it; it sets no stage.

**A global cloud region.** Nothing held says a global cloud provider runs a region beside [the data centres](<https://africa.hyperscalers.news/news/wingu-africa-launches-tier-iii-data-center-in-djibouti/>). Only a live region of a public cloud provider answers this question; an announced region, a content cache or an edge site does not.
