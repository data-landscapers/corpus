# DR Congo

## Data centres for hire in service

**In service, Tier III, and two of them.** [Communications Africa states two Tier-III data centres opened in Kinshasa in August 2024: Raxio DRC1 and OADC Texaf Digital](<https://communicationsafrica.com/internet/drcs-largest-data-centre-opens>). [La Tribune (Agence Ecofin, 2026-09-18) says WIOCC's subsidiary Open Access Data Centres operates a network of more than 40 data centres stretching from Nigeria to the Democratic Republic of Congo, implying an operating OADC colocation site in the DRC](<https://www.latribune.fr/article/afrique/70618725438421/data-centers-wiocc-prepare-un-bond-de-capacites-en-afrique-avec-l-appui-americain>). [Open Access Data Centres, owned by wholesale operator WIOCC, already runs six hyperscale facilities and more than thirty edge sites across South Africa, the DRC and Nigeria](<https://techtrends.africa/edge-computing-in-africa/>). [Raxio DRC is described in the release as a Tier III certified carrier-neutral facility; the release does not name the certifying body, and the statement is made by the KINIX/Raxio release itself, dated 2026-08-20](<https://www.raxiogroup.com/raxio-drc-to-host-kinshasa-internet-exchange-kinix-strengthening-national-connectivity/>). Together these place two data centres for hire at Tier III or above in service, which answers the first three of the study's four questions. Capacity is given where a source states it; it sets no stage.

**A global cloud region.** Nothing found says a global cloud provider runs a region beside [the data centres](<https://communicationsafrica.com/internet/drcs-largest-data-centre-opens>). Only a live region of a public cloud provider answers this question; an announced region, a content cache or an edge site does not.
