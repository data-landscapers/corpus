# Zambia

## Data centres for hire in service

**In service, Tier III, and two of them.** [The Zambian government's ministerial statement describes the active Zambia National Data Centre (ZNDC), which hosts private clients for a fee, as a Tier 3 facility (stated by the government; no certifier named)](<https://www.parliament.gov.zm/sites/default/files/images/publication_docs/Ministerial%20statement%20on%20PROGRESS%20ON%20THE%20SMART%20ZAMBIA%20VISION.pdf>). [Paratus Zambia Vanguard Data Centre (Paratus Zambia), colocation/carrier-neutral, in service](<https://www.techtrends.co.zm/paratus-partners-with-zadara-to-deliver-next-generation-cloud-services/>). [Data Landscapers' June 2026 register of carrier-neutral African data centres states that Paratus runs five data centres across Angola, Namibia and Zambia, so it has one or more in Zambia](<https://data-landscapers.com/2026/06/11/sovereign-infrastructure/>). [The Xalam Analytics brief for the EU D4D Hub estimates Zambia had roughly 5 live commercial data centre facilities in 2024, with about 2MW of live critical IT load and about 60% occupancy; it names no facility in this count](<https://cms.d4dhub.eu/assets/Initiatives/Data-Governance-in-Africa/Digital-Investment-Facility/2507_Country-Market-Briefs/Data-Center-Market-Brief-Zambia.pdf>). These place a data centre for hire at Tier III or above in service, which answers the first two of the study's four questions. A second at Tier III is not stated. Capacity is given where a source states it; it sets no stage.

**A global cloud region.** Nothing found says a global cloud provider runs a region beside [the data centres](<https://www.parliament.gov.zm/sites/default/files/images/publication_docs/Ministerial%20statement%20on%20PROGRESS%20ON%20THE%20SMART%20ZAMBIA%20VISION.pdf>). Only a live region of a public cloud provider answers this question; an announced region, a content cache or an edge site does not.
