# Burkina Faso

## Data centres for hire in service

**In service, Tier III, and two of them.** [BTW Media describes VTS's Virtix data centre in Ouagadougou, in service and offering colocation, as Tier III, with no certifying body named (an operator-profile claim)](<https://btw.media/it-infrastructure/virtual-technologies-solutions-burkina-faso-connectivity-provider/>). [IKA Solution LTD launched IKA Cloud on 31 July 2026 in Ouagadougou, a data hosting centre in Burkina Faso built with technical support from Virtual Technology, selling web hosting, VPS, dedicated servers and server colocation to outside customers, and reporting 600+ domain names, 196+ web hosting accounts and 98% availability at launch](<https://lefaso.net/spip.php?article148312>). [BTW Media reports that Virtual Technologies & Solutions (VTS) runs the Virtix data centre in Ouagadougou, which offers colocation, cloud and hosting services](<https://btw.media/it-infrastructure/virtual-technologies-solutions-burkina-faso-connectivity-provider/>). These place a data centre for hire at Tier III or above in service, which answers the first two of the study's four questions. A second at Tier III is not stated. Capacity is given where a source states it; it sets no stage.

**A global cloud region.** Nothing found says a global cloud provider runs a region beside [the data centres](<https://btw.media/it-infrastructure/virtual-technologies-solutions-burkina-faso-connectivity-provider/>). Only a live region of a public cloud provider answers this question; an announced region, a content cache or an edge site does not.
