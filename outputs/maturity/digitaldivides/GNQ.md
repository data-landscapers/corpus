# Equatorial Guinea

## Rural internet gap

**Rural connectivity programme.** [In November 2023 the Vice-President ordered Huawei to draw up a project for telephone and internet coverage of the whole territory](<https://www.guineaecuatorialpress.com/noticias/la_calidad_de_la_red_telefonica_podria_mejorar_proximamente>). [It includes the interior and is to be assessed before a first phase is approved](<https://www.guineaecuatorialpress.com/noticias/la_calidad_de_la_red_telefonica_podria_mejorar_proximamente>). [In April 2023 the state infrastructure manager GITGE linked the island province of Annobon to the national fibre network](<https://news.identicge.org/annobon-ya-dispone-de-internet-de-alta-velocidad/>). [The link is a submarine cable from Sao Tome, laid before the three-year window](<https://news.identicge.org/annobon-ya-dispone-de-internet-de-alta-velocidad/>).
