# Mali

## Use by other systems

**Register keyed on ID.** Mali's electoral roll is drawn from the national identification number, NINA. In January 2025 L'Essor reported that [the administrative commission enrols voters automatically](<https://lessor.ml/posts/loi-electorale-les-articles-52-57-et-70-modifies-677641a527512>) from those who hold a NINA. In October 2026 [a report on cleaning the electoral roll](<https://bamada.net/fichier-electoral-lheure-du-grand-nettoyage>) named NINA as each voter's unique identifier, with a biometric civil status database behind the lists.

**Main registers.** The nearest fact is [the October 2026 report on the electoral roll](<https://bamada.net/fichier-electoral-lheure-du-grand-nettoyage>). It names the voter lists as built on NINA. It names no other public register using the number.

**Matching reported.** The nearest fact is [L'Essor's account of the electoral law](<https://lessor.ml/posts/loi-electorale-les-articles-52-57-et-70-modifies-677641a527512>), as amended in 2024. It sets out how voters holding a NINA are entered on the roll without enrolling themselves.

***Also on file***. None found.

***Not found***. No source found since October 2023 shows a second main register using NINA. None gives a figure from checking a register against the ID.
