# Djibouti

## Use by other systems

**Register keyed on ID.** Djibouti has made its national identification number, the NNI, compulsory for data exchange between public bodies. [The Ministry of Digital Affairs said in 2024 that all institutions must use the NNI](<https://numerique.gouv.dj/Articles/detailArticleAvancee/15>) when they exchange data. An interoperability platform with ANSIE is being set up. No source found since October 2023 shows a public register in service with the NNI.

**Main registers.** No main register is shown using the NNI. [The ministry's 2024 statement](<https://numerique.gouv.dj/Articles/detailArticleAvancee/15>) names no electoral roll, tax register, payroll, social registry or business register.

**Matching reported.** No figure from checking a register against the ID has been found. [The ministry's statement](<https://numerique.gouv.dj/Articles/detailArticleAvancee/15>) describes a platform still being built. It gives no count of records exchanged or checked.

***Also on file***. None found.

***Not found***. No source found since October 2023 shows a public register using the NNI.
