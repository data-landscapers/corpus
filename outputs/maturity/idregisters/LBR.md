# Liberia

## Use by other systems

**Register keyed on ID.** [The Civil Service Agency integrates National Identification Numbers into government employees' ID cards through the NIR portal, and Sargbe says this has helped remove ghost names from the payroll](<https://frontpageafricaonline.com/news/liberia-national-identification-registry-drives-digital-transformation-with-strategic-partnerships-and-enrollment-growth/>). [The NIR and the finance ministry built an interface to audit the government payroll against the registry as new employees join, shared with the audit and civil service agencies](<https://newspublictrust.com/national-identification-registry-deploys-mobile-teams>). [The paper's findings state the NEC and NIR databases operate as two separate databases, so the voter register is not drawn from the NIR](<https://doi.org/10.22271/allresearch.2025.v11.i6d.12680>).

**Main registers.** No source found since October 2023 shows three or more main public registers using the national ID number. The nearest held fact: [the one given above](<https://frontpageafricaonline.com/news/liberia-national-identification-registry-drives-digital-transformation-with-strategic-partnerships-and-enrollment-growth/>).

**Matching reported.** [The NIR says a 2018 payroll cleanup using registry attributes found only 60,000 of about 80,000 payroll names showed up (2018, before the three-year window)](<https://newspublictrust.com/national-identification-registry-deploys-mobile-teams>).
