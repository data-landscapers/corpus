# Botswana

## Use by other systems

**Register keyed on ID.** Botswana registers voters on Omang, the national identity card. [In August 2026 the minister proposed electoral reforms that keep Omang as the primary ID for voter registration](<https://allafrica.com/stories/202608190305.html>). The same reforms would give political parties access to the verified electronic voters' roll. The roll is the one public register found using the Omang number.

**Main registers.** One main register is shown: the voters' roll. No source found since October 2023 shows the tax register, the public payroll, a social registry or the business register using the Omang number. [The minister's reforms](<https://allafrica.com/stories/202608190305.html>) name only the electoral roll.

**Matching reported.** No figure from checking a register against the ID has been found. [The August 2026 reforms](<https://allafrica.com/stories/202608190305.html>) speak of a verified roll. They give no count of records matched or removed.
