# Burkina Faso

## Use by other systems

**Register keyed on ID.** In October 2024 the minister in charge, Aminata Zerbo, said [the electoral commission would draw its voter file from the new identity base](<http://news.aouaga.com/h/155610.html>) once it is built. Voters would then no longer be enrolled afresh for each election. The base is the unique electronic identifier being built under the WURI project, with a pilot to come first.

**Main registers.** The nearest fact is [the minister's account of the identity base](<http://news.aouaga.com/h/155610.html>). It names the electoral file as the first register to be drawn from it. Mass enrolment was to aim at 80 per cent of the population.

**Matching reported.** The nearest fact is [the same account](<http://news.aouaga.com/h/155610.html>), of October 2024. The electoral commission, CENI, enrols voters for each election, and the minister set out how the identity base would replace that.

***Also on file***. [Carte d'identité biométrique AES (CIB-AES)](<https://www.sidwaya.info/carte-didentite-biometrique-aes-au-burkina-faso-le-capitaine-ibrahim-traore-pour-commencer/>).

***Not found***. No source found since October 2023 shows a public register using the national ID number.
