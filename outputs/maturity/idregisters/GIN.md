# Guinea

## Use by other systems

**Register keyed on ID.** Guinea plans to draw its voter file from the national register of persons. [In January 2026 the electoral directorate, DGE, and ONECI signed a convention on it](<https://mediaguinee.com/2026/01/conakry-la-dge-et-loneci-scellent-une-alliance-pour-un-fichier-electoral-fiable/>). It makes the register's data the sole official source of voter identity for the biometric electoral file, the DGE's director-general said. The register is the registre national des personnes physiques, RNPP.

**Main registers.** No main register is shown using the national ID number. In December 2025 the electoral directorate's head said [the voter roll will be fed from the register by a yearly extraction](<https://www.lindependant.org/actualites-etat-civil-guineen-la-refondation-en-marche-lidentification-au-coeur-du-futur-fichier-electoral/>). At the launch of the civil service file FUGAS in November 2025, the Prime Minister said [each official's unique identification number must be built into it](<https://www.africaguinee.com/modernisation-de-ladministration-le-gouvernement-lance-officiellement-le-fugas/>). No source found since October 2023 shows the file in use.

**Matching reported.** No figure from checking a register against the ID has been found. [The convention](<https://mediaguinee.com/2026/01/conakry-la-dge-et-loneci-scellent-une-alliance-pour-un-fichier-electoral-fiable/>) gives no count of voter records matched. No audit of the electoral file against the register has been found.

***Also on file***. [Registre national des personnes physiques (RNPP)](<https://www.guinee114.com/2026/09/18/matd-dge-djenabou-toure-lance-latelier-sur-lextension-du-registre-national-des-personnes-physiques/>).

***Not found***. No source found since October 2023 shows a public register using the national ID number.
